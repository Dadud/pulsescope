# Native decoder fixture corpus

These deterministic, synthetic fixtures exercise transport and failure handling without redistributing captured radio traffic. They were generated by PulseScope contributors from protocol layouts documented in ICAO Annex 10, ITU-R M.1371, AX.25 2.2, ETSI EN 300 133, and IEC 62106. No third-party recording or implementation was copied.

License: MIT, matching the repository. `manifest.json` records provenance, expected disposition, impairment, and SHA-256 for every artifact. JSON fixtures encode interleaved complex-f32 values as `[I,Q]` pairs and are intentionally short so their provenance is auditable.
